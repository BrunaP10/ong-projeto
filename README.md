# ONG Esperança

Projeto acadêmico desenvolvido para a criação de um site institucional fictício para a ONG Esperança.

O projeto apresenta informações sobre a organização, seus projetos e disponibiliza um formulário de cadastro para participação.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Vite
- Git
- GitHub
- Vercel

## Funcionalidades

- Página inicial da ONG
- Apresentação dos projetos
- Formulário de cadastro
- Navegação entre as páginas
- Validação dos dados do formulário
- Armazenamento dos dados de cadastro no `localStorage`
- Interface responsiva
- Recursos de acessibilidade

## Acessibilidade

O projeto foi desenvolvido considerando as diretrizes de acessibilidade da WCAG 2.1 nível AA.

Foram aplicadas melhorias como:

- Uso de HTML semântico
- Textos alternativos para imagens
- Navegação estruturada
- Utilização de atributos `aria-label` quando necessários
- Campos de formulário identificados corretamente
- Contraste adequado entre elementos
- Estrutura de conteúdo organizada para facilitar a navegação
