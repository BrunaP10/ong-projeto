# ONG Esperança

Projeto acadêmico desenvolvido em HTML, CSS e JavaScript.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Página inicial da ONG
- Seção de projetos
- Formulário de cadastro
- Navegação entre conteúdos
- Validação de dados
- Armazenamento do cadastro no localStorage
- Melhorias de acessibilidade

## Versionamento

O projeto utiliza Git e GitHub para controle de versões, seguindo uma organização baseada no GitFlow.
